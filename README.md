# SmartKart Customer Churn Analysis

## 📌 Project Overview

This project analyzes customer data from SmartKart to understand customer behavior and identify patterns associated with customer churn.

The dataset contains 100 customer records with information about their age, monthly spending, complaints, and churn status.

## 🎯 Objectives

- Analyze customer demographics
- Understand monthly customer spending
- Study the relationship between complaints and churn
- Identify patterns in customer churn
- Perform basic data cleaning and analysis
- Generate useful insights from the dataset

## 📊 Dataset

The dataset contains the following columns:

| Column | Description |
|---|---|
| Customer_ID | Unique ID of each customer |
| Age | Age of the customer |
| Monthly_Spend | Customer's monthly spending |
| Complaints | Number of complaints made by the customer |
| Churn | Indicates whether the customer has churned |

### Churn Values
- `1` = Customer churned
- `0` = Customer did not churn

## 🔍 Analysis Performed

- Data inspection

- Visualization of important patterns
- Relationship analysis between spending, complaints, age, and churn

## 📈 Key Questions

1. How many customers have churned?
2. Does the number of complaints relate to churn?
3. Does monthly spending differ between churned and non-churned customers?
4. Which age groups show higher churn?
5. What customer characteristics are associated with churn?

## 💡 Expected Outcome

The analysis aims to help SmartKart understand customer behavior and identify patterns that can support better customer retention strategies.
